# Canal corporativo (React + React Router)

    npm install
    npm run dev

Rutas: `/registro` (formulario) → `/home` (plataforma de videos). `/home` redirige a `/registro` si no hay sesión.
Ajusta `src/data/enums.js` a tus enums Rol y Departamento, y el verde en `--verde` de `src/styles.css`.
